What these checks cover

Text is rendered with the real compiler output, selected family and available project fonts. Base test viewports are 900px tall; modeled zoom divides both width and height. Root font size follows typography.base (16px fallback). The selected runtime controls --ec-zoom at each zoom step. It affects only declarations that actually use that variable; fixed pixel rules are not multiplied.

“--ec-zoom follows zoom” models proportional compensation, assuming the runtime detects zoom correctly. “Jupiter Chrome (DPR)” models the current Jupiter Chrome calculation starting at 100% page zoom on one display; DPR is the display ratio at that starting point, not your current zoomed devicePixelRatio. Monitor changes, initial loads already zoomed, pinch zoom and other browser detectors require real-site testing.

The 320px reflow and text-spacing tests look for overflowing or clipped specimen text. Spacing overrides use at least 1.5 line height, 2em after paragraphs, 0.12em letter spacing and 0.16em word spacing. They are user overrides, not required design defaults. Full page layouts and functional content still need testing.

Also check on your site: real browser zoom, keyboard navigation and focus visibility, control target sizes, meaningful names and alt text, reduced motion, and contrast over images/gradients. No site-wide pass is inferred here.
